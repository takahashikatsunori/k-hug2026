# **HUG（避難所運営ゲーム）動的カードデータベース詳細設計書 V6.2**

## **1\. 概要およびデータベース設計方針**

### **1.1 設計の目的**

本ドキュメントは、避難所運営ゲーム（HUG）において訓練条件（季節、天候、避難所、災害種別、時間帯等）に応じたカードデッキを動的に生成・制御するための「カードデータベース」のデータ構造およびフォーマットを定義するものです。

### **1.2 データモデルおよび対象DB**

本データベースは、複雑な避難者構成や配列形式の条件判定を柔軟に保持するため、**JSON構造を扱えるドキュメント指向DB（MongoDB、Firestore等）またはRDBのJSONB型での運用を前提**とします。  
データモデルは以下の3つの主要コレクション（テーブル）から構成されるリレーションシップ構造を採用します。

> * **イベントカードマスタ (cards\_event)**：災害被害、行政対応、外部問い合わせ、施設トラブル等の出来事カードを保持する。  
> * **避難者グループマスタ (evacuee\_groups)**：避難者の世帯・グループ単位の基本情報、私物資機材、避難元、およびカード出現条件を保持する。  
> * **避難者構成員＆ペットマスタ (group\_members)**：各避難者グループに属する個人およびペットの詳細属性（人物：要配慮特性・体調・スキル、ペット：健康・配慮・スキル・飼育方法等）を1行（1レコード）単位で保持する。

### **1.3 2段階制御ロジック（①カード抽出 ➔ ②デッキ並び順ソート）**

本データベースでは、パラメータの役割を「カードを検索抽出するためのフィルタ条件」と「抽出後にデッキを順番づけるためのソート条件」の2段階に明確に分離します。  
\[訓練条件入力\]  
 ├── 検索パラメータ（避難所, 天候, 時間帯, 災害種類, インフラ状況, 休日区分 等）  
 └── ソートパラメータ（災害進行度, 相対発生時期）  
       │  
       ▼  
【第1段階：カード抽出（フィルタリング）】  
  ( match\_配列が空 OR 訓練条件値 IN match\_配列 ) AND NOT ( 訓練条件値 IN exclude\_配列 )  
       │  
       ▼  
【第2段階：デッキ並び順割り付け（ソート・配置）】  
  抽出されたカード群に対し、「災害進行度」や「相対発生時期」の設定値を元に  
  デッキの前半・中盤・終盤等へ並び替えを実行

#### **【第1段階：カード抽出判定ルール】**

> * **未指定（Null / 空配列 \[\]）の扱い:** 「その条件での絞り込みを行わない（すべての条件値に適合する）」と解釈します。  
> * **合致条件 (match\_\*):** 未指定、または訓練入力値が配列内に含まれている場合に適合します。  
> * **排除条件 (exclude\_\*):** 訓練入力値が配列内に含まれている場合、無条件で不採用（除外）とします。

## **2\. テーブル詳細定義**

### **2.1 イベントカードマスタ (cards\_event)**

避難所運営中に発生する各種イベント、問合せ、行政連動、トラブル等を管理するテーブルです。

| 物理名 | 論理名 | データ型 | 必須 | 説明・定義内容 |
| :---- | :---- | :---- | :---- | :---- |
| card\_id | カードID | 文字列(PK) | ○ | 一意の識別子（例: EV-001） |
| event\_name | イベント名 | 文字列 | ○ | カードのタイトル（例: 給水車の到着） |
| category | 種別 | 複数選択 | ○ | 【選択肢群 1.1 参照】イベントの分類 |
| priority | 優先度 | 数値 | ○ | 0〜10の整数。数値が小さいほど優先発生（0は確定発生） |
| difficulty | 対応難易度 | 選択 | ○ | 【選択肢群 1.2 参照】課題の解決難易度 |
| must\_respond | 対応必須フラグ | 選択 | ○ | 【選択肢群 1.3 参照】ゲーム一時停止を伴う必須課題か否か |
| prerequisite\_card\_id | 前提カードID | 文字列 | \- | このカードが出現するために事前に対象デッキに含まれている必要があるカードID（連鎖用） |
| source | 発生源 | 文字列 | \- | イベントの発生元（例: 市災害対策本部、近隣住民） |
| additional\_equipment | 追加資機材 | 文字列 | \- | イベントに伴い発生・搬入される資機材（例: 毛布20枚） |
| required\_people | 必要人数 | 数値 | \- | 対応に必要な人員数 |
| content | イベント内容 | 文字列 | ○ | 伝言事項や指示内容の本文 |
| scene\_description | 情景・読み上げ | 文字列 | \- | カード読み上げ用または現場の情景テキスト |
| training\_point | 訓練ポイント | 文字列 | \- | 参加者に気づかせたい対応判断・指導の鍵 |
| **【検索抽出用条件】** |  |  |  |  |
| match\_shelters | \[合致\] 避難所 | 複数選択 | \- | 【選択肢群 2.1 参照】対象の避難所（空は全施設適合） |
| exclude\_shelters | \[排除\] 避難所 | 複数選択 | \- | 【選択肢群 2.1 参照】除外する避難所 |
| match\_dates | \[合致\] 日付 | 範囲テキスト | \- | 対象日付・期間（例: 01/01-01/03） |
| exclude\_dates | \[排除\] 日付 | 範囲テキスト | \- | 除外する日付・期間 |
| match\_holiday\_type | \[合致\] 休日種別 | 複数選択 | \- | 【選択肢群 2.2 参照】該当する休日区分 |
| exclude\_holiday\_type | \[排除\] 休日種別 | 複数選択 | \- | 【選択肢群 2.2 参照】除外する休日区分 |
| match\_time\_slots | \[合致\] 時間帯 | 複数選択 | \- | 【選択肢群 2.3 参照】発生時間帯 |
| exclude\_time\_slots | \[排除\] 時間帯 | 複数選択 | \- | 【選択肢群 2.3 参照】除外する時間帯 |
| match\_disaster\_types | \[合致\] 災害種類 | 複数選択 | \- | 【選択肢群 2.4 参照】適用される災害種別 |
| exclude\_disaster\_types | \[排除\] 災害種類 | 複数選択 | \- | 【選択肢群 2.4 参照】除外される災害種別 |
| match\_infrastructure | \[合致\] インフラ状況 | 複数選択 | \- | 【選択肢群 2.5 参照】インフラ障害条件 |
| exclude\_infrastructure | \[排除\] インフラ状況 | 複数選択 | \- | 【選択肢群 2.5 参照】除外するインフラ障害条件 |
| match\_weather | \[合致\] 天候 | 複数選択 | \- | 【選択肢群 2.6 参照】気象条件 |

| relative\_timing | 相対発生時期 | 複数選択 | \- | 【選択肢群 3.2 参照】デッキ順序制御用の配置時期 |

### **2.2 避難者グループマスタ (evacuee\_groups)**

避難時に一団（1世帯・1グループ）として到着する単位を管理するテーブルです。

| 物理名 | 論理名 | データ型 | 必須 | 説明・定義内容 |
| :---- | :---- | :---- | :---- | :---- |
| group\_id | グループID | 文字列(PK) | ○ | 一意の識別子（例: GRP-001） |
| group\_name | 世帯・グループ名 | 文字列 | ○ | カード表示用のグループ名称（例: 高橋家、旅行者3人組） |
| member\_count | 一行人数 | 数値 | ○ | 構成員の合計人数 |
| evacuation\_origin | 避難元 | 選択 | ○ | 【選択肢群 4.1 参照】避難者がどこから来たか（地域・町丁目） |
| urgency\_level | 到着時緊急度 | 選択 | ○ | 【選択肢群 4.2 参照】受付時に優先対応を要する度合い |
| personal\_equipment | 私物資機材 | 複数選択 | \- | 【選択肢群 4.3 参照】グループが持ち込む大型資機材・車両 |
| pet\_count | ペット頭数 | 数値 | ○ | 同行するペットの総数（0以上の整数） |
| match\_\* / exclude\_\* | 検索条件群 | 複数選択 | \- | cards\_event と同様の全検索抽出フィールドを保持 |
| disaster\_phase | 災害進行度 | 複数選択 | \- | 【選択肢群 3.1 参照】デッキ順序制御用の発災経過段階 |
| relative\_timing | 相対発生時期 | 複数選択 | \- | 【選択肢群 3.2 参照】デッキ順序制御用の配置時期 |

### **2.3 避難者構成員＆ペットマスタ (group\_members)**

避難者グループに所属する人物およびペット個々の属性情報を管理するテーブルです。group\_idを介してevacuee\_groupsと外部キー参照（1対多）で紐付きます。

| 物理名 | 論理名 | データ型 | 必須 | 説明・定義内容 |
| :---- | :---- | :---- | :---- | :---- |
| member\_id | 構成員ID | 文字列(PK) | ○ | 一意の識別子（例: M-0001） |
| group\_id | グループID | 文字列(FK) | ○ | 所属するグループID（evacuee\_groups.group\_idを参照） |
| data\_type | データ種別 | 選択 | ○ | 「人物」または「ペット」 |
| name | 名前 | 文字列 | \- | 個人の名前 / ペットの名前（空欄の場合はデッキ生成時に自動生成） |
| gender | 性別 | 選択 | \- | 【選択肢群 5.2 参照】性別 |
| age | 年齢 | 数値 | \- | 満年齢（数値） |
| **【人物用属性（data\_type \= 人物 の場合に使用）】** |  |  |  |  |
| relationship | 続柄・関係 | 選択 | \- | 【選択肢群 5.1 参照】世帯主との関係またはグループ内での立場 |
| attributes | 属性 | 複数選択 | \- | 【選択肢群 5.3 参照】社会的位置付け・役割 |
| vulnerabilities | 要配慮特性 | 複数選択 | \- | 【選択肢群 5.4 参照】身体的・社会的要配慮要件 |
| health\_condition | 体調・ケガ | 複数選択 | \- | 【選択肢群 5.5 参照】健康状態・外傷・疾患状況 |
| skills | スキル | 複数選択 | \- | 【選択肢群 5.6 参照】保有資格・特技・協力可能な職能 |
| statement | 受付時の言葉 | 文字列 | ○ | 避難者が抱えている状況を受付に説明した内容・セリフ |
| **【ペット用属性（data\_type \= ペット の場合に使用）】** |  |  |  |  |
| pet\_type | 種別 | 選択 | \- | 例：犬、猫、小型鳥類、ウサギ、爬虫類 等 |
| pet\_health\_condition | ペット健康属性 | 複数選択 | \- | 【選択肢群 6.1 参照】病気、ケガ、特殊管理等 |
| pet\_vulnerabilities | ペット配慮属性 | 複数選択 | \- | 【選択肢群 6.2 参照】しつけ、鳴き声、ワクチン等 |
| pet\_skills | ペットスキル | 複数選択 | \- | 【選択肢群 6.3 参照】性格・能力等の特性 |
| pet\_housing | 飼育方法 | 複数選択 | \- | 【選択肢群 6.4 参照】連れてきた状態・必要なケージ種別 |
| **【共通テキストフィールド】** |  |  |  |  |
| appearance | 容姿・特徴 | 文字列 | ○ | 服装、見た目の特徴、所持品などの補足情報 |
| training\_point | 訓練ポイント | 文字列 | ○ | 個人・ペット対応における判断ポイント・指導事項 |
